Patent Information

Title Gesture-based user interface
Publication US20220261083A1
Publication Date Aug 18, 2022
Assignee Capital One Services LLC

Inventors

David Franklin, Van Shea Sedita, and Stephen Simpson.

Abstract Summary

The publication describes a computer program that can enter a gesture-based mode, receive sensor-generated gesture information from a user, and perform an action based on that input. When a gesture is ambiguous, the interface can suggest possible commands and learn relationships between gestures and selected actions.

Claim Themes

Gesture mode: The system activates a mode designed for gesture-based interaction.

Gesture data: The system receives input from sensors or a user interface.

Suggested commands: The interface can offer likely commands when intent is unclear.

Execution: The selected command is carried out and may be associated with the gesture.
